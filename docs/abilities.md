# Added Abilities

Abilities from later generations that work in battle here. Every other newer ability is the
closest Gen 3 ability (see each Pokémon's page). Healer, Telepathy and Honey Gather only matter
with a partner or outside battle, and Quark Drive needs Electric Terrain or Booster Energy,
which Gen 3 does not have, so those four have no effect in battle here.

| Ability | What it does |
|---|---|
| Adaptability | Powers up same-type moves. |
| Aftermath | Hurts the foe as it faints. |
| Anticipation | Senses the foe's danger. |
| Beast Boost | KOs raise its best stat. |
| Big Pecks | Prevents DEFENSE reduction. |
| Bulletproof | Blocks ball and bomb moves. |
| Competitive | Stat cuts raise SP. ATK. |
| Defiant | Stat cuts raise ATTACK. |
| Dry Skin | Likes water, hates fire. |
| Filter | Dulls super-effective hits. |
| Flower Veil | Guards GRASS types' stats. |
| Fluffy | Halves contact damage. |
| Frisk | Checks the foe's held item. |
| Healer | May heal a partner's ills. |
| Heatproof | Halves FIRE-type damage. |
| Honey Gather | May gather HONEY. |
| Hydration | Heals status in rain. |
| Ice Body | Slight HP recovery in hail. |
| Iron Barbs | Hurts the foe on contact. |
| Iron Fist | Powers up punching moves. |
| Justified | Ups ATTACK if hit by DARK. |
| Leaf Guard | No status problems in sun. |
| Motor Drive | ELECTRIC moves raise SPEED. |
| Moxie | KOs raise ATTACK. |
| Multiscale | Less damage at full HP. |
| Poison Touch | May poison on contact. |
| Prankster | Status moves go first. |
| Prism Armor | Dulls super-effective hits. |
| Protosynthesis | Sun ups its best stat. |
| Quark Drive | Electric field ups a stat. |
| Rattled | Ups SPEED when frightened. |
| Reckless | Powers up recoil moves. |
| Regenerator | Recovers HP on switch-out. |
| Rivalry | Stronger vs same gender. |
| Sand Force | Powers up moves in sand. |

| Sap Sipper | GRASS moves raise ATTACK. |
| Slush Rush | Ups SPEED in hail. |
| Sniper | Powers up critical hits. |
| Snow Cloak | Ups evasion in hail. |
| Snow Warning | Summons hail in battle. |
| Solid Rock | Dulls super-effective hits. |
| Stamina | Ups DEFENSE when hit. |
| Storm Drain | WATER moves raise SP. ATK. |
| Strong Jaw | Powers up biting moves. |
| Super Luck | Raises critical-hit ratio. |
| Sweet Veil | Prevents sleep. |
| Technician | Powers up weak moves. |
| Telepathy | Dodges a partner's attacks. |
| Tinted Lens | Boosts resisted moves. |
| Tough Claws | Powers up contact moves. |
| Weak Armor | Hits drop DEF and up SPEED. |
